# cycling
Cycling data releated scripts

- MATTS_sync
    WIP: Script is designed to compare race envents between different sources (BikeReg, WP Events, & Strava)

- RaceResults
    An attempt to normalize race results from many years of MATTS races (see Results tab on www.ambikerace.com)
    This never was finished but the SQL Schema file I think was well thought out.
    The list of race categories was completed.

- Bikelog
    The scripts I've used since 1993 to track my workouts.  Moving forward it will also be using API calls to fetch
    data from Strava.  It already fetches data from the Withings API (see bin/withings.sh)
